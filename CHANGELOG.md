# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-08

### Added
- Initial release of Cozy Light website
- Responsive design for all devices
- Dark mode support with toggle button
- Scroll animations (fade-in effects)
- Mobile-friendly navigation menu
- CSS variables for easy color customization
- Configuration file (config.js) for centralized settings
- Image placeholder system
- Comprehensive documentation:
  - README.md with editing guide
  - DEPLOY.md with deployment instructions
  - images/README.md with image guidelines
- Placeholder image generation script (generate-placeholders.py)
- Favicon (SVG format)
- Package.json for npm scripts

### Pages
- **index.html**: Homepage with hero section, features, showcase, and CTA
- **features.html**: Detailed feature descriptions with images
- **specs.html**: Product specifications and color options
- **about.html**: Company story, values, and contact information

### Technical Features
- Pure HTML/CSS/JavaScript (no frameworks)
- CSS custom properties for theming
- Intersection Observer for scroll animations
- Local storage for dark mode preference
- Responsive breakpoints: 480px, 768px, 1024px
- Smooth scrolling for anchor links
- Mobile menu with hamburger button
